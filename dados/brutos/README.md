# dados/brutos/

Aqui ficam as respostas **originais e não alteradas** das APIs consultadas,
organizadas por fonte e por execução (uma subpasta por coleta, nomeada com
o UF e o horário da execução).

Regra: nada aqui é editado depois de salvo. Se um dado no banco parecer
estranho, a forma de conferir é abrir o arquivo bruto correspondente e ver
exatamente o que a fonte respondeu naquele momento.
